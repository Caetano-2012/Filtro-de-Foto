
# Filtro de Foto

Este projeto é um aplicativo web interativo que utiliza P5.js, ml5.js e Bootstrap para aplicar filtros de imagem em tempo real no rosto do usuário. O filtro principal é um par de óculos pixelados, detectado e posicionado através de técnicas de Machine Learning para rastreamento facial.

Além de ser um recurso divertido, o projeto tem caráter educativo, demonstrando de forma prática como é possível integrar visão computacional e interfaces criativas na web. O usuário pode experimentar o filtro diretamente na câmera e capturar selfies personalizadas.


## Stack utilizada

**Front-end:** html, css, javascript, P5.js, ml5.js e Bootstrap.
